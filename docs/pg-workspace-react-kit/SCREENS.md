## 2. 업무 모듈 공통 템플릿 — `ModulePage`

8개 화면이 동일 템플릿을 공유한다. 화면별 차이는 `data/modules.ts` 설정과 §2.1 표뿐이다.

```
.heading   [eyebrow PAYMENT OPERATIONS] [메뉴명] [sub]                    [primary 액션]
(.banner)  ← 정산·지급에서만
card ┬ .tabs           탭 n개 (활성 .on)
     ├ (.mapnote)      탭 index > 1 이고 탭 필터 미정의일 때 안내문
     ├ .filters        [검색 input flex:1] [상태 select] [초기화] [↓ CSV]
     └ #results        DataTable + .tablebottom(샘플 n건 · 1 / 1)
```

공통 동작:

- 검색: 행 6칸 전체를 공백으로 이은 문자열에 대해 대소문자 무시 부분일치
- 상태 select: `전체 상태` + 해당 모듈 행의 상태값 중복 제거 목록
- 탭 변경 / 초기화: 검색어·상태 초기화 (탭은 유지)
- ↓ CSV: 현재 필터 결과를 `pg-{moduleId}-sample.csv` 로 저장 + T `현재 조회 결과를 내보냈어요`
- 행 클릭 / 행 포커스 후 Enter → [D] 상세 (§3)
- 빈 결과: `조회 결과가 없어요. 검색 조건을 변경해 주세요.`
